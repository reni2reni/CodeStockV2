This code is for a Chrome extension. To use it, you need to register it with Chrome. Switch to developer mode, register this folder, pin it to the top right of your browser, and then use the "Open Subpanel" option in the menu that appears when you click it. (To incorporate BF6 blocks, you need Portal Browser Extension and its plugin, Copy-BF-6.)
1. Portal Browser Extension
https://bf2042-portal-extensions.lennardf1989.com/dist/manifest.json
Plug-in
2. Adds Copy and Paste block
https://andy6170.github.io/Copy-Paste/manifest.json
3. Adds a Variable Manager
https://andy6170.github.io/Blocky-Unlimited-Variables/manifest.json

Sample data for BF6 is located in the DATA folder; please import and use it. Please refer to the included PNG images for details on each function.
