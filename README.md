This code is for a Chrome extension.
To use it, you need to register it as a Chrome extension.
Switch to developer mode, register this folder, pin it to the upper right corner of your browser, and then use it by clicking "Open subpanel" in the middle of the menu that appears when you click it.
(To incorporate BF6 blocks, you need Portal Browser Extension and its plugin, Copy-BF-6.)
Sample data for BF6 is in the DATA folder; please import and use it.
Please refer to the included PNG images for details on each function.
